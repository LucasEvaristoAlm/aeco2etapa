Apresentação

Este trabalho apresenta um sistema que recomenda áreas de atuação em Tecnologia da Informação. A recomendação é feita a partir das respostas de um questionário sobre interesses, tecnologias e preferências de trabalho.

O sistema foi desenvolvido em Python. A interface foi feita com Streamlit e as regras de recomendação usam a biblioteca Experta.

Funcionamento

O questionário reúne informações do perfil do usuário. Depois, o motor compara as respostas com as regras cadastradas e calcula uma pontuação para cada área. Ao final, mostra a área recomendada, as demais opções do ranking e as regras que foram utilizadas.

O projeto tem 38 regras: seis criam indicadores sobre o perfil, vinte atribuem pontos às áreas, dez ajudam a diferenciar áreas parecidas e duas definem o resultado final ou uma opção padrão quando as respostas não são suficientes.

Implementação e testes

O código separa a interface, as perguntas, os dados das áreas profissionais e o motor de regras. Essa organização permite alterar o questionário ou as regras sem concentrar tudo em um único arquivo.

Os testes verificam as regras, as recomendações para diferentes perfis, os casos em que duas áreas podem ser confundidas e o comportamento para respostas inconclusivas. Ao executar python -m pytest -q, foram aprovados 17 testes.

Conclusão

O projeto aplica um sistema baseado em regras para relacionar as respostas do questionário a possíveis áreas de atuação em TI. O resultado serve como uma sugestão inicial e não substitui uma avaliação profissional. As regras foram definidas para o trabalho e podem ser aprimoradas com novos testes e opiniões de usuários.
